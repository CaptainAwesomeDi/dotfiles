# FAQ

**What is end-to-end testing?**
End-to-end testing verifies that a complete user workflow works correctly across the system.

**When should end-to-end tests be added?**
Add end-to-end tests for critical user flows and regressions that are hard to catch with lower-level tests alone.

**Why keep end-to-end tests focused?**
Focused end-to-end tests are easier to maintain, faster to run, and clearer to debug when failures happen.
